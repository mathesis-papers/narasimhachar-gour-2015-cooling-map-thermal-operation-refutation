# 冷却而不降能：四个能级为何比三个不同？

把一栋楼的四层标成能量 $0,1,3,7$。一个很冷的环境不能把能量送给楼内的物体，因此物体只能留在原层或向下走。这似乎已经概括了“冷却”的全部限制。可是量子系统还保存另一种信息：不同能级之间波的相对关系。本文的例子让每层的测量概率始终等于 $1/4$，只改变这种关系。一个合法的抽象冷却规则能做到；任何本文所指的有限冷浴都做不到，甚至不能无限逼近。

本文依据 Haobo Ma、Wenlin Zhang 的论文 [Four-level closure separation at Narasimhachar–Gour's Conjecture 1 (Supplementary Sec. S2 F, p. S11): beyond Maestro's exact qutrit separation (2026), using Dykema–Juschenko (2009)](https://doi.org/10.5281/zenodo.24209470)第 3 版。下文的原文定理和章节编号均指这一版本。

楼层比喻只描述能量与概率。量子态不是一枚藏在某层的硬币。以两个能级为例，$(|0\rangle+|1\rangle)/\sqrt2$ 与“各以一半概率选一个能级”的混合态，能量测量结果相同，但在先把两个波重新组合的实验中会不同。前者有**相干性**，即可以干涉的相对振幅；后者没有。数学上，我们用一个表格——密度矩阵——同时记录两类信息。对角线是各能级的概率，非对角线记录相干性。这里的反例藏在非对角线上。

本文作者为 **Haobo Ma**（ChronoAI Pte Ltd, Singapore）与 **Wenlin Zhang**（National University of Singapore；ChronoAI Pte Ltd, Singapore）。本解说对应其公开论文第 3 版，保留原作者姓名。原文见[第 3 版论文 PDF](https://mathesis-omega-research.apps.chrono-ai.fun/api/v1/collected-papers/narasimhachar-gour-2015-cooling-map-thermal-operation-refutation/files/pdf?version=3)。

## 先分清三个问题

“两个规则能否完成同一个状态变化”比“两个规则是不是同一个通道”弱。一个通道规定所有输入怎样变化；反驳通道相等，并不自动找到了一个无法实现的特定输入输出对。本文给出这样的具体一对。

还要分清**精确实现**与**任意逼近**。有理数不能精确等于 $\sqrt2$，却可以任意逼近它；“每个有限方案都不相等”并不能排除极限方案。本文排除的不只是精确等号，还在目标周围留出一个所有有限方案都进不去的小邻域。误差下界是保守的 $10^{-8}$，并未声称它是最优常数。

最后，本文的“冷浴”有严格定义：环境维数有限且非零；初态是在**完整最低能量子空间上均匀混合**的状态；联合演化严格守恒总能量。环境最低能量可以简并，简并度没有上限。一般正温度浴、无限环境、催化辅助均不属于主结论。

## 阅读路线

第一章把一个 $3$–$4$–$5$ 直角三角形变成合法的四能级冷却通道。第二章解释“不降平均能量”为什么迫使环境中的四个动作都是可逆的，并用两行代数找出矛盾。第三章把精确矛盾变成统一误差界。第四章说明四能级阈值、推广与已有文献，并准确划分形式证明的范围。
